# DeskKit 参考组件

包含系统状态、Codex 额度、国内金价三个 `.deskkit` 组件。它们仅供参考，不保证在另一台电脑上立即可用；默认停用。

解压 ZIP 后，在 DeskKit 中导入对应的 `.deskkit` 文件夹。应用首次启动已安装同名样例时，直接修改并启用即可；不要重复导入相同 ID。

自行编写或调整 `render.js` 与 `widget.json`。可以把例子和 PluginGuide.md 交给大模型模仿构建，但需要自己核对生成内容。

- 系统状态：按本机网络接口与系统环境调整。
- Codex 额度：另行安装并登录兼容的 Codex 客户端；需要时填写本机可执行文件位置。
- 国内金价：依赖第三方网站，接口可用性、格式和使用条件可能变化。

包内只包含参考代码与说明，没有作者的账号、缓存、签名配置或本机路径。请勿把自己的秘密数据加入准备分享的组件包。
